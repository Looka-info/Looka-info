Featured project
DemandCast — ML Forecasting System
A forecasting research project built around reproducible evaluation and production-oriented engineering practices.
- Time-series evaluation: rolling-origin backtesting across public retail datasets.
- Model comparison: baseline forecasts and experimental seasonal-calibration strategies.
- Evaluation integrity: point-in-time data contracts, paired comparisons, and segment-level error analysis.
- ML infrastructure: FastAPI, MLflow, SQLite persistence, Docker, and GitHub Actions.
- Governance: experimental challengers remain separate from the active baseline; no automatic promotion.
Evaluation is based on historical data. An external live retail feed is not currently connected, and experimental candidates have not been promoted to production.
