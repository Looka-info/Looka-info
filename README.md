### 🌿 PlantVision — Plant Leaf Disease Classifier

[![Repository](https://img.shields.io/badge/Explore_Project-Computer--vision--classifier-181717?style=flat&logo=github)](https://github.com/Looka-info/Computer-vision-classifier)

An end-to-end PyTorch computer vision system that compares a custom convolutional neural network against fine-tuned ResNet-18 for classifying plant leaf diseases across 38 categories of the PlantVillage dataset.

#### 🔬 Engineering Highlights

- **Dataset Integrity:** Implemented SHA-256 hashing, difference hashing (dHash), and multi-index hashing to identify duplicate and near-duplicate image candidates.
- **Leakage Prevention:** Audited more than 2.28 million cross-split image-pair candidates and addressed specimen overlap between training, validation, and test partitions.
- **Transfer Learning:** Implemented a two-stage ResNet-18 fine-tuning strategy with head warm-up and differential learning rates.
- **Model Calibration:** Evaluated confidence reliability using Expected Calibration Error and implemented a validation-derived rejection threshold for uncertain predictions.
- **Performance Benchmarking:** Compared the custom CNN and ResNet-18 using classification metrics, synchronized CUDA timing, and throughput measurements.
- **Interactive Inference:** Built a Streamlit application that presents top-three predictions and reliability alerts.
- **Automated Testing:** Includes a Pytest suite covering core project functionality.

**Tech stack:** Python · PyTorch · TorchVision · Scikit-learn · NumPy · Pandas · CUDA · Streamlit · Pytest

## 🧪 Engineering Philosophy

**01 — Data integrity before model complexity**

A sophisticated model cannot compensate for contaminated datasets, duplicate samples, or evaluation leakage.

**02 — Evidence over assumptions**

Compare models against baselines using reproducible experiments, appropriate metrics, and isolated test data.

**03 — Calibrated confidence over raw predictions**

A useful model should communicate uncertainty, not merely produce a class label with a high confidence score.

**04 — Measured performance over theoretical performance**

Benchmark real inference workloads, account for hardware synchronization, and distinguish startup overhead from steady-state execution.

**05 — Models should solve real problems**

Build practical applications that make predictions, analytics, and model limitations accessible to their intended users.
